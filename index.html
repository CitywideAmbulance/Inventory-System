Create Inventory Item

Instructions:
• Select a Category from the dropdown.
• Select an Item from the dropdown.
• Select a Location (stockroom) to allocate the item to.
• Press the camera icon to scan or type the Barcode (if available).
• Type the Lot number (if available).
• Choose an Expiration date (if available).
• Enter the Quantity you are adding to stock.
• Once you are finished, press Save item and the data will be transferred to the database.

Camera preview
When checked, item saves with no category — for shared stockroom items that apply to both bags and vehicles.

Equipment Inventory

Instructions:
• Press the camera icon to scan a barcode or type the lot number/item name and press the search icon in the first column.
• Existing equipment: fields lock and the fields for Assigned Location and Current Status remain editable.
• Missing item: fill fields.
• Select a Location from the dropdown.
• Select a Status from the dropdown.
    - Active status will have new fields appear for date returned, in-service date, and upcoming service date.
    - OOS status will have new fields appear for the service reason, comments, and date shipped.
• Once you are finished, press Save Equipment and the data will be transferred to the database.

ALS Bag Restock

Scan items, enter quantities, submit

Instructions:
• First, select a bag number from the dropdown above the table.
• Select the Stock Location to pull inventory from.
• Press the camera icon to scan a barcode or type the lot number/item name and press the search icon in the first column.
• Existing item: fields lock and Bag Qty remains editable.
• Missing item: fill fields, choose replacement, then click Add & Use.

Stock Transfer

Instructions:
• Scan a barcode with the camera icon or type a name, barcode, or lot to search. Optionally filter by location first.
• Click Select on the row you want to move from.
• Choose the Destination Location to move stock into.
• To issue directly to an employee, select Employee as the destination and enter their ID number.
• Enter the Quantity and optional notes, then press Transfer to confirm.

Narcotics

Instructions:
• First, select a Mode from the dropdown.
    - Create Narc is used to add the narc to the overall stock.
    - Narc Kit Restock is used to move the selected narcs to the designated kit.
    - Narc Kit Verification is used to mark the active content inside of a kit.
• Select a Location from the dropdown.
• Enter the data for each field.
• Once you are finished, press Save Narc/Submit All and the data will be transferred to the database.

Fleet Inventory

Instructions:
• Scan the barcode with the camera icon or type it manually.
• Fill in the part details — at minimum a Part Name or Barcode is required.
• Enter the quantity and unit cost.
• Use the Location fields to specify exactly where this part is stored (Aisle, Rack, Row).
• Press Save Part when finished.
